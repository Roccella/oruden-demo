# Oruden demo

Demo of Oruden, a browser editor for arranging an apartment in 2D and 3D.

Live at https://roccella.github.io/oruden-demo/

It opens on an empty plan: draw rooms, add openings and furniture, and switch between
the 2D plan and the 3D view. Everything runs in the browser, so there is no account and
no backend, and the document is kept in the browser's own storage.

This repo holds the built demo and nothing else. A deploy script replaces it on every
release, so it is never edited by hand.
